## 1. Root Cause Analysis

### Cause of Rejection in Take v2
In Take v2, Shot 4 (OVER-CAP) only performed a `smoothScroll(page, 0)` instead of a fresh page reload. Because `run()` in `public/app.js` did not clear or hide `#results` upon button submission, the red "BLOCKED" panel from Shot 3 (`scam.near` / `counterparty_block`) remained visible on screen while the 0.7 NEAR testnet transaction was in flight (~20 seconds). A viewer saw a "BLOCKED" outcome before the over-cap run actually executed.

### Polish Items Identified
1. **Caption / Typing Desynchronization**: In Shot 3 (and Shot 2/4), the caption stated "Typed Prompt Injection... Clicking Run Guard" ~3 seconds before the payee field was actually typed. Captions must clearly distinguish the "Typing..." window from the "Typed..." state.
2. **Chrome Automation Infobar**: The banner "Chrome is being controlled by automated test software" was visible. It should be suppressed using `ignoreDefaultArgs: ['--enable-automation']` in Playwright's `launchPersistentContext`.
3. **Dead Wait Visibility**: When an on-chain transaction is in flight, the UI should show an explicit pending state ("Signing on testnet..." button + spinner + status message) and no old verdict. If the dead wait exceeds ~8 seconds, the segment should be sped up using ffmpeg `setpts` and labeled "(sped up)" in the caption.

## 2. Step-by-Step Execution Plan

### Step 1: Update Frontend (`public/app.js`, `public/index.html`, `public/styles.css`)
- In `public/index.html`:
  - Add `<div id="pending-row" class="pending-row" hidden>` with a spinner and descriptive text below `.run-row`.
- In `public/styles.css`:
  - Add styles for `.pending-row` and `.pending-spinner` matching the dark terminal theme.
- In `public/app.js`:
  - When `run(body)` is invoked:
    - Set `$('run').disabled = true;` and `$('run').textContent = 'Signing on testnet...';`
    - Explicitly hide and clear previous results: `$('results').hidden = true;` and `$('results').dataset.runSeq = '';`
    - Display the pending row: `$('pending-row').hidden = false;`
  - In `finally`:
    - Restore `$('run').disabled = false;` and `$('run').textContent = 'Run guard';`
    - Hide `$('pending-row').hidden = true;`
  - In `render(r)`:
    - Unhide `$('results')`, update `data-run-seq`, and populate verdict.
